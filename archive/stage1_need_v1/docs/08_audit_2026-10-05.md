# Full audit (2026-10-05)

Three independent read-only audits: (A) data generators and gold, (B) inference and scoring code,
(C) recomputing every number in the docs from raw jsonl. Scratch scripts were kept outside the repo.

## Verified correct

- Gold: re-parsed from the rendered text (not metadata) and recomputed. Pilot 476/476 numeric/itemized,
  ladder 5000/5000, v2 dev 1600/1600, v2 test 4800/4800.
- Reproducibility: every committed data file regenerates byte-for-byte from the documented seeds
  (pilot needs `--controls`). IDs unique; v2 dev/test pools disjoint; v2 conditions exactly balanced.
- Sequence label scoring: prefix equals the generation prompt (Qwen: empty think block, thinking off;
  Ministral: `[/INST]`), prompt_logprobs aligned, prefix_mismatch = 0. SHORTFALL/SUFFICIENT have equal
  token counts per model (Qwen 3/3, Ministral 4/4), so unnormalized sums are valid.
- Meaning mapping correct for all 17 queries (synthetic tests pass). Bootstrap resamples bases.
- All committed score.json files reproduce byte-for-byte. Doc numbers recompute (exceptions below).

## Qwen3-14B oracle ladder (sequence-level)

Accuracy 1.00 in every context x level x query cell, both gold classes; unemployed-minus-none 0.0;
0 monotonicity violations; correct label wins by >= 5.5 nats (median 17-31). Not a copy of the 8B run
(SUFF log-prob r = 0.98 with 8B, 11,935 distinct score triples). Meta lacks rendered prompts (run
started before the provenance commit). Score file: results/diagnostic_seq/qwen3-14b.score.json.

**Consequence:** the "unemployed-specific" failure has support in 1 of 3 models (Ministral's L0 gap
is an option-order prior, employed > unemployed). Outline branch 2 applies; see decisions.md retarget.

## Qwen3-8B anti-monotonic curve (unemployed/L0, need labels)

- Not a template artifact: within a base only the funds number changes across gaps.
- Broad, within-base: 43/50 bases fall from +2% to +40%; median within-base Spearman -0.90.
  Tracks absolute surplus (accuracy 0.75 -> 0.07 by surplus quintile).
- Template-dependent: the bookkeeper/"accounting firm" template resists (0.72), others 0.25-0.44.
  Job and loss templates are 1:1 confounded (5 templates).
- Untested hypothesis: "income, savings, and any outside help" may read as implausible for someone
  with no paid work, interacting with large sums.
