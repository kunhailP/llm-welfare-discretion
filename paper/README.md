# Manuscript

**Response Protocols Shape Deservingness Effects in LLM Welfare Decisions**

`main.tex` is the anonymous ARR short-paper source. `references.bib` contains only the references cited in the manuscript and appendix. The official ACL style files are unchanged.

```bash
make -C paper
```

Requirements: `latexmk` and TeX Live with the ACL template's packages. The build produces `paper/main.pdf`.

Regenerate the analyses before building with `python src/eval/reproduce.py` from the repository root. In a Git checkout, `make -C paper sync PY=python3` additionally checks whether the generated tables differ from the tracked versions; a difference requires review, including after an intentional edit.

Numbers are recorded in `docs/paper1/tables.md` and `results/`. `appendix_tables.tex` is generated by `src/eval/make_paper1_appendix.py`; do not edit it directly. `rule_packet_fy2026.md` is a verbatim copy of the prompt packet in `configs/`.

The paper reports the replication criterion's post-hoc origin, the limited independent gold cross-check, incomplete follow-up conditions and the distinction between zero observed flips and equivalence. Preserve those qualifications when editing.
